# 视觉、页面与交互规范

关联：[范围](README.md) · [架构](architecture.md) · [实施与验收](implementation-plan.md)

本文件的颜色、尺寸和时长是**拟实施设计规范**，不是当前网站的测量结果。实施时可为真实内容的行长和布局微调；改变整体风格、页面结构或交互流程须由主 agent 决定。

## 1. 设计语言

现代个人工作室；清楚、轻快、带少量可触摸的物件感。大面积安静背景，真实内容建立视觉重点，收藏台承担主要趣味。避免每块内容都套相同卡片、无限漂浮、渐变发光背景、满屏打字机和鼠标尾迹。

设计参数参考：布局变化 7/10，动效强度 6/10，信息密度 4/10。首页动效较强；简历与回答正文动效最低。网站有完整深浅主题，同一主题内不突然反转某个 section。

## 2. 颜色契约

使用语义变量，不把颜色散落到组件。下表变量统一采用 `--studio-` 前缀，避免覆盖旧主题。

| 后缀 | Light | Dark | 用途 |
| --- | --- | --- | --- |
| `bg` | `#F5F6F8` | `#111318` | 页面背景 |
| `surface` | `#FFFFFF` | `#1B1F27` | 有实际层次的表面 |
| `ink` | `#171A22` | `#F3F5F8` | 标题、主要正文 |
| `muted` | `#5B6270` | `#A6AEBD` | 次要正文、元信息 |
| `line` | `#D9DEE7` | `#343C4A` | 非交互性分隔线 |
| `control-border` | `#7B8495` | `#758095` | 需要清楚辨识的输入/控件边界 |
| `accent` | `#3156D3` | `#90A8FF` | 链接、选中状态、强调按钮 |
| `on-accent` | `#FFFFFF` | `#111318` | 强调按钮文字 |
| `accent-soft` | `#E8EDFF` | `#252F49` | 轻量选中背景 |
| `focus` | `#3156D3` | `#90A8FF` | 可见聚焦轮廓 |

规则：

- 只使用一个品牌强调色；项目概念艺术可以有自然材质颜色，但不能给各栏目新增一套按钮色。
- Light/Dark token 随现有主题 class 生效；不另建第二套主题状态。
- error/loading 状态复用现有组件中语义正确的处理，并加文字说明，不能只靠颜色区分。
- `line` 不作为控件唯一可见边界；交互边界用 `control-border` 或等效清晰外形。
- 设计阶段使用 JavaScript 按 sRGB 线性化相对亮度公式计算，比例为 `(L较亮+0.05)/(L较暗+0.05)`：Light 主文字 16.09、次文字 5.67、accent 链接 5.71、按钮文字 6.17；Dark 对应 17.01、8.33、8.17、8.17。这些是规定纯色背景的静态参考，不是本仓库浏览器无障碍验收结果；透明、hover、focus 和组件组合须重新检查。

## 3. 字体、间距与形状

### 字体

- 首版复用已确认的 `"Helvetica Neue", Helvetica, Arial, sans-serif`；等宽使用 `ui-monospace, "SFMono-Regular", Menlo, monospace`，不临时从第三方 CDN 加字体。
- 若现有字体不支持需要的字重，先选择可靠 fallback，新增本地字体作为独立决定。
- 首页主标题：桌面约 56–72px、小屏约 36–44px，行高 1.05–1.15，最多约三行；真实姓名和文案不允许裁切。
- 页面标题：40–56px；section：28–36px；正文：16–18px，行高 1.6–1.75；辅助信息：13–14px。
- 等宽字体仅用于短技术元信息；正文与简历不整段等宽。
- 不通过过小字号或低对比度来掩盖内容密度问题。

### 布局

- 常规页面最大内容宽度 1200px，居中。
- 桌面水平留白约 32–48px；手机 20px，极窄宽度最低 16px。
- 阅读内容（简历正文/聊天消息）另设易读行长，避免强行撑满 1200px。
- 间距使用 4、8、12、16、24、32、48、64、96px 的有限层级。
- 导航高度约 72px，首屏标题、主要入口与收藏台应同时可见；不硬设整屏高度撑空白。
- 用内容与设备宽度决定断点：至少验证 390、768、1024、1440px，不把桌面-only 的 Sidekick 约束移入此个人网站。

### 形状

- 小控件圆角 10px；普通媒体 18px；收藏台的大表面 26px。
- pill 只用于明确的标签/筛选或胶囊按钮；不能随意混用。
- 阴影只用于物件深度和浮层，不给每段文字套浮起的卡片。
- 点击目标至少 44×44px，键盘聚焦轮廓约 2–3px 并留偏移空间。

## 4. 公共导航与页面状态

桌面：姓名/品牌入口在左，Home、Projects、Resume、Ask、Music、Photos 与主题切换在右；允许通过省略显式 Home 并以品牌回首页减少拥挤，但六页都必须易到达。

窄屏：使用现有可访问的折叠菜单或简单菜单；可键盘操作、Escape 关闭、正确恢复焦点。不要为了放六项把字缩得很小。

导航当前项有文字或位置反馈，不只依赖颜色。普通 `<Link>` 路径是基础；动画永远不能吞掉点击、焦点或浏览器返回。

需要统一覆盖：正常、hover、focus、active、loading、error、empty。只有真实异步操作才显示 loading；没有内容不能伪装成一直加载。

## 5. Home `/`

### 信息结构

1. Hero：姓名、基于已有资料的一句定位、最多两三行简介、Projects/Resume 入口。
2. 右侧收藏台：现有头像和五个物件入口。
3. Featured work：Conductor、Engram、FigBrain，使用真实配置。
4. 简洁的 Experience 与 About，保留旧锚点；不复刻完整简历。
5. Music/Photos 的清晰入口；无内容时只能表达栏目正在等待个人收藏。
6. 页脚联系链接。

桌面 hero 为文字/视觉双栏；1024px 及以下采用单栏。768px 以下，收藏台取消绝对定位/重叠式布局，五个入口按两列排列，末项自然占一个格子，头像在入口区上方或隐藏为纯装饰；手机先身份与按钮，后入口区。物件标签永远可见，不允许仅缩放整张桌面画布来塞入小屏。

### 收藏台

| 物件 | 基础行为 | 桌面增强 | 无动画/触屏 |
| --- | --- | --- | --- |
| 项目叠卡 | 跳转 `/projects` | 卡片错开 6–12px，轻微抬起 | 固定叠卡与文字标签 |
| 简历纸 | 跳转 `/resume` | 纸面轻抬，阴影变化 | 直接点击 |
| 对话气泡 | 跳转 `/chat` | 显示一个来源于配置的简短问题 | 固定 Ask 标签 |
| 唱片 | 跳转 `/music` | 唱片移出封套一小段 | 不旋转，不暗示正在播放 |
| 相框 | 跳转 `/photos` | 空相框扇形展开 | 空相框，不用假照片 |
| 头像 | 个人形象，默认非操作控件 | 极轻位移/旋转 | 静态图片 |

物件保持真实导航语义。允许同页 hover/focus 展开，不做 drag。视差使用 fine pointer 且 reduced-motion 关闭时才启用，最大约 6–10px/2–3°；离开区域时归位。物件之间不得遮挡标签或触控区域。生成封面不用于伪装正在运行的项目演示。

## 6. Projects

### 列表 `/projects`

- 标题、短介绍、All / AI & ML / Full-stack 筛选。
- 筛选保持现有 `track` 参数语义；不可只存在内存中。
- 第一个 featured 项目可占宽版，其他项目形成有节奏的网格；不强迫八项都相同尺寸。
- 卡片信息：概念图或诚实的文字封面、名称、短说明、少量技术标签、详情入口。
- UI 短名称仅为呈现映射，完整项目标题保留在配置和详情，不复制第二份事实描述。
- 没有素材的项目使用一致的文字型封面，不能复用其他项目图造成误认。
- 筛选导致的布局变化可动画，但移出的卡片不应保留可聚焦的隐藏链接。
- 保持直接刷新、浏览器前后退和返回列表时筛选参数。

### 详情 `/projects/[slug]`

顺序：返回项目 → 标题/summary → 概念封面 → 已有 description/achievements → 技术栈/时间/状态 → 实际存在的外部链接。

页面可以简短。无真实 Demo、代码链接时省略按钮，不放 disabled 占位 CTA。指标只按现有资料表达，不能自行补评价方法。无效 slug 返回正常 404。

### 封面艺术方向

- Landscape 3:2；同一正交/轻等距镜头、冷灰白环境、哑光材质与钴蓝细节。
- Conductor：模块、分岔轨道、checkpoint gate，表达工作流与恢复。
- Engram：半透明索引层片、被抽出的记忆片，表达上下文检索。
- FigBrain：几何部件在画布上组合，表达设计生成。
- 图像内不生成项目名称、界面文字或假产品仪表盘；标题由页面渲染。
- 使用说明「Concept artwork」或等效文案，且 alt 说明图像是概念表达。
- 后续实施时生成、人工视觉检查、优化格式并绑定仓库资产；当前文档不触发生图。
- 建议优化后封面每张不超过约 300KB，明确 width/height 或 aspect-ratio；目标允许根据实际质量调整并记录。

## 7. Resume `/resume`

保留现有事实顺序、PDF 下载、相关 tracking 和主要阅读结构。只调整字体层级、间距、色彩与导航一致性。正文可选择复制，打印时去掉导航和装饰。新 wrapper 不改变已有下载事件调用。

动效：最多一次短淡入，不逐条延迟揭示经历，不让简历必须滚动触发才可打印。

## 8. Ask `/chat`

### 初始状态

头像、简短提问邀请、三到四个配置驱动问题、输入框。不要把全部职业资料重复铺在此页。`?q=` 沿用当前发送与初始化语义，不能重复提交。

### 对话状态

- 消息有合适行宽，composer 不覆盖最后一条消息，手机键盘弹出仍可用。
- 保持已有 streaming、tool-result、fallback、错误显示语义。
- 用户主动向上阅读时不强制反复滚到底部；改动前先确认当前自动滚动逻辑。
- 图标或头像可表达等待、真实请求中、完成；没有请求时不伪造 thinking。
- 文本不做逐字跳动；失败必须可理解，停止/重试只有在现有接口支持且行为明确时复用。
- 新来源卡片/citation 系统不属于本次；若已有项目跳转，仅用已验证的站内地址。

## 9. Music `/music`

首版：标题、简短说明、视觉唱片、未来选曲区域和明确空状态。英文草案可用「No records here yet.」；不得暗示用户正在听某首歌。

唱片是栏目视觉，不是无法工作的播放器。没有音源时不显示播放、进度、音量、播放队列或假播放时间。hover 可轻移唱片；idle 不持续转动。

以后真实内容进入时，由单独任务选择 provider/embed/external link/合法可服务音频及是否持续播放。本次不提前承诺跨页音频能力。

## 10. Photos `/photos`

首版：标题、简短说明、空相框、自然空状态。英文草案可用「No photos published yet.」；不虚构拍摄地点、日期、旅行记录。

不显示不可操作的上传按钮或相册筛选。相框可以有一次短入场/hover 展开。真实照片提供后再实现按比例排列与 accessible lightbox，当前不预写复杂观看器。

## 11. 统一动效表

| 类别 | 建议参数 | 约束 |
| --- | --- | --- |
| hover/focus | 150–220ms，最多约 4px lift | focus 与 hover 反馈等价 |
| 内容入场 | 280–420ms，位移 8–16px | 单个延迟不超过约 200ms |
| 收藏台初次出现 | 总体约 600–700ms | 立即可交互，不阻塞导航 |
| 同页布局变化 | 300–450ms | 可打断，不闪烁，不改变语义阅读顺序 |
| 轻弹性 | stiffness 260 / damping 26 / mass 0.8 起点 | 真实页面调节，避免明显反复弹跳 |
| reduced motion | 静态或短透明度变化 | 禁用位移、缩放、旋转、视差、持续运动 |

禁止同时由 CSS transform 和 Motion 对同一节点争用 transform；需要组合时使用清晰的内外层。不要用 React state 跟踪每帧鼠标/滚动。首版只做路由进入，不承诺 Next App Router 的跨路由 exit/shared-element 行为。

## 12. 视觉验收最少覆盖

- 390/768/1024/1440px，无横向溢出、标签遮挡、按钮换行挤压。
- 深浅两套主题，输入边界、placeholder、hover、focus、disabled/error 状态。
- 只用键盘访问所有物件、导航、筛选和聊天；触屏无需 hover。
- reduced-motion 系统设置开启时，收藏台保持完整稳定布局。
- 内容加载和图片解码时没有明显布局跳动；首次 HTML 内容不因动画脚本失败长期透明。
- Resume 打印和 Chat 流式长内容不被装饰影响。
